# YouTube transcripts and captions in Python

The transcript example retrieves **existing caption tracks** using FlashData. It does not transcribe audio and does not create captions for videos that have none.

```bash
python -m examples.flashdata_transcript VIDEO_ID --language en --output output/transcript.json
python -m examples.flashdata_transcript VIDEO_ID --language en --manual-captions --output output/manual-transcript.json
```

Replace `VIDEO_ID` with a real 11-character video ID. The default uses automatic captions (`auto=True`). `--manual-captions` requests uploader-provided captions (`auto=False`). The example does not silently switch caption type if your requested track is missing.

For automatic captions, FlashData may select the original-language variant of the requested language. Inspect the returned `languageCode`, rather than assuming it is exactly the value you passed.

## Response fields

The full API response is saved. Each returned track can include:

- `videoId`: the source video.
- `languageCode`: the returned track's language.
- `isAutoGenerated`: whether the caption track is automatically generated.
- `fullText`: the combined caption text.
- `segments`: timestamped entries with `start`, `end`, and `text`.

The dataset example keeps the full valid tracks in `transcripts`. When a requested track is unavailable, it preserves the video and its available metadata with an error status. A failed transcript request does not erase successfully collected metadata.

## Google's caption endpoint

The Google examples here are public-data examples authenticated with an API key. Google's `captions.download` requires OAuth and permission to edit the video, so it is not used as a general public transcript endpoint in this toolkit.

References: [FlashData transcript API](https://flashdata.dev/docs/sources/youtube_transcript), [Google caption download](https://developers.google.com/youtube/data/reference/rest/v3/captions/download).
